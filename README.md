# Transfusion Academy

Plateforme pédagogique responsive consacrée à la sécurité transfusionnelle.

## Fonctionnalités

- six modules de formation ;
- progression locale ;
- simulateur avec cinq situations ;
- quiz avec correction immédiate ;
- checklist pré-transfusionnelle ;
- fiches imprimables, glossaire et recherche globale ;
- ressources institutionnelles et assistant pédagogique de démonstration.

## Lancer localement

Ouvrir `dist/index.html` dans un navigateur ou servir le dossier `dist` avec un serveur statique.

## Publication GitHub Pages

Dans les paramètres du dépôt, ouvrir **Pages**, choisir **Deploy from a branch**, puis la branche `main` et le dossier `/docs` si le contenu est déplacé dans ce dossier, ou utiliser un workflow Pages pour publier `dist`.

## Avertissement

Ce site est destiné à la formation et ne remplace pas les protocoles de l'établissement, les recommandations professionnelles ou une décision médicale.
